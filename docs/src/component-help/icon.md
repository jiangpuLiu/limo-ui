# Icon

Commonly used Icon.

## Icon API

### Attributes

| Name         | Description                           | Type                  | Default         |
| ------------ | ------------------------------------- | --------------------- | --------------- |
| name         | Icon name                             | ^[string]             | ''              |
| size         | Icon size, rendered as size x size    | ^[number]             | 16              |
| color        | Icon color                            | ^[string]             | currentColor    |
| strokeWidth  | Stroke width of the icon              | ^[number]             | 2               |
| defaultClass | Default class for the icon            | ^[string]             | lucide-icon     |
| fill         | Fill color of the icon                | ^[string]             | none            |
